# 빙빙제로 — 공개 실자료 버전

React/TypeScript/Leaflet 앱. `npm ci`, `npm test`, `npm run build`, `npm run dev`로 설치·검증·실행한다.

첫 화면에서 강남 말죽거리 지도를 보여준다. ‘목적지 입력하기’를 누르면 출발지·목적지 검색 화면이 열린다. 관악과 강남의 상세 자료를 자동으로 사용하고, 그 밖의 서울 경로와 자치구를 지나는 경로는 `public/data/seoul/`의 OSM 보행 타일을 필요할 때 불러온다. 타일은 같은 Geofabrik 원본으로부터 `scripts/build-seoul-walk.py`로 추출하며 원본 OSM 노드와 보행 권한·방향을 보존한다. 타일과 표고 파일의 해시는 인덱스에 기록한다.

서울 전역에서 Open-Meteo 시간별 기상, 기상청 초단기·단기예보, 인근 AWS 관측, 동결점 근처의 기상청 500m 지점 분석을 적용한다. OSM 건물 높이와 Copernicus GLO-30의 30m 간격 자료로 구간의 그늘을 계산한다. 관악과 말죽거리의 과거 예보는 해당 지역에서 선택할 수 있다. 보행망이 연결되지 않아 TMAP 일반 경로를 보여주는 경우에도 서울에서는 불러온 공개 보행망에 결빙 예상을 표시한다.

`public/data/osm.json`은 Geofabrik의 2026-11-17 한국 OSM PBF에서 실제 관악구 영역을 추출한 자료다. `provenance.json`과 `verification.json`에 원본·추출본 해시, 기준시각, 원본 재검사 결과를 보존했다. 앱 로딩 시 SHA-256을 확인한다. 1,222개 노드/1,502개 구간/902개 등록 객체이며 독립된 시설 902곳이라는 의미는 아니다.

같은 PBF에서 서울대입구역 관계 8469467에 속한 출입구 노드 1~8번을 대조해 장소 검색에 추가했다. 검색 대상은 총 910개다. 출구를 검색하면 동명의 자전거 대여소·정류장과 구별한다. 출구와 인근 보행망 사이의 직선거리 4.94~13.55m는 경로 거리와 소요시간에서 제외한다.

도보 권한과 방향은 원본 태그를 바탕으로 처리한다. 경사·계단 정보 누락을 임의로 채우지 않는다. 장소와 실제 도로 노드 사이 공백은 80m까지 허용하되 경로/시간에서 제외하고 별도 표시한다.

보도별 실제 결빙 상태는 미확인이다. 재결빙 예상구간과 일반 경로가 겹치면 해당 보행선 전체를 제외한 대체 경로를 계산한다. 두 경로의 예상 거리·시간과 안내 구간을 비교할 수 있다.

지도의 ‘결빙 예상’에서 앞으로 24시간의 시각을 선택할 수 있다. 기온 0°C 이하에 강수·눈 등 물기 근거가 들어오면 추정 그늘과 실외 보행 교량을 점선으로 표시한다. 최근 30분 안에 확인한 관측소의 1시간 강수를 해당 관측소에서 3km 이내의 분석 구역에 적용한다. 선택 시각의 직전 6시간에 관측된 1시간 전체가 들어와야 한다. 서리나 어는 비·이슬비 예보는 지역 주의 정보로 표시한다.

서울시 열선 설치 기록 중 공개 보행선과 대조한 말죽거리·일원 보도육교는 강설 조건에서 경로 비교 가중치에 반영한다. 열선 정보는 화면에 따로 노출하지 않는다. 보도별 제설 완료와 실제 결빙은 미확인이다.

서울대입구역 1번출구에서 5번출구로 검색한 뒤 ‘예보·지도 설정’의 ‘과거 예보로 비교’를 선택하면 2025년 1월 27일 11시 KST의 공개 과거 기상 원본으로 일반 경로와 우회 경로를 비교한다. 배포된 응답 파일의 SHA-256을 확인한 뒤 계산한다.

최신 예보의 같은 시각에는 기상청 초단기예보, 단기예보, Open-Meteo 순으로 기온을 선택한다. 기상청 강수 예보도 지역 강수 근거로 쓴다. 발표 시각과 시간별 기상 근거를 표시한다.

엔진과 기상 테스트는 취득한 실제 원본을 사용한다. 오류 검증에서는 실제 응답 필드를 누락시키거나 읽는 시각을 바꾼다. 테스트에는 실제 출구 검색 순서, 접근 공백과 출구별 관악구청 경로도 포함한다.

장소 검색어는 서버가 TMAP 검색에 전달한다. TMAP 보행 경로가 필요한 때에는 선택한 장소의 이름과 좌표도 전달한다. 검색·경로 이력은 저장하지 않는다. 장소검색·최단경로(10)·계단제외(30)는 해당 앱에 TMAP 상품이 연결된 유효 키를 필요로 한다.

로컬 서버 설정은 Git 제외 파일 `.env.local`의 `KMA_API_KEY`, `TMAP_APP_KEY`를 사용한다. 서울시 기상은 공식 공개 표를 HTTPS로 조회하며 인증이 필요 없다. 배포판은 같은 변수 이름을 사용하는 서버 Worker이며 `npm run build`가 화면과 서버를 함께 빌드한다. 비밀값을 클라이언트용 `VITE_` 설정에 넣지 않는다.
